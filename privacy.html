Privacy policy

This OAuth app is used only by the owner's private, self-hosted Home Assistant instance.

  • Data accessed: the owner's Google Calendar events, to display them on a home screen and to add events.
  • Storage: the access token and calendar data stay on the owner's own Home Assistant server at home. Nothing is sent to any third party.
  • Sharing: no data is sold, shared or used for advertising or any other purpose.
  • Revoking access: at any time from myaccount.google.com/permissions.

Google user data handling complies with the Google API Services User Data Policy, including the Limited Use requirements.
